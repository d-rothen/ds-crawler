# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use [GitHub's private vulnerability reporting
form](https://github.com/d-rothen/ds-crawler/security/advisories/new) and include
the affected version, impact, reproduction steps, and any suggested mitigation.
Remove credentials and private dataset contents from the report unless they are
strictly necessary to reproduce the issue.

You should receive an acknowledgement after a maintainer reviews the report.
Release timing and disclosure will be coordinated according to severity and
the availability of a safe fix.
